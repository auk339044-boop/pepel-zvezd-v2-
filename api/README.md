Официальный веб-портал и защищённая система двусторонней поддержки проекта **«Пепел звёзд»**. Проект объединяет минималистичный космический интерфейс, мгновенный веб-чат с синхронизацией через Telegram Forum Topics и многоуровневую систему кибербезопасности на базе аппаратного фингерпринтинга и PostgreSQL.

---

## 🚀 Ключевые возможности

### 💬 Двусторонний Real-Time чат поддержки (Web ↔ Telegram)
* **Бесшовная маршрутизация тикетов:** Обращения с сайта автоматически создают изолированные ветки (`Forum Topics`) в закрытой группе администраторов с тегами категорий (`#отзыв_XXXXXXX`, `#админ_XXXXXXX`).
* **Мгновенная синхронизация (WebSockets + Webhooks):** Ответы администраторов из веток Telegram перехватываются через Webhook (`/api/tg-webhook`), сохраняются в PostgreSQL и в реальном времени доставляются в диалоговое окно на сайте без перезагрузки страницы.
* **Безопасный парсинг ссылок:** Автоматическое распознавание и подсветка ссылок внутри переписки с защитой от XSS-инъекций и утечки `Referer`.

### 🛡 Многоуровневая система безопасности и Anti-Fraud
* **Кросс-браузерный Hardware Fingerprinting (`SHA-256`):** Генерация уникального идентификатора устройства на основе рендера **HTML5 Canvas**, параметров видеокарты **WebGL**, звуковой сигнатуры **OfflineAudioContext**, аппаратной конфигурации и часового пояса.
* **Поведенческий Auto-Ban & Кластеризация:** Автоматическая блокировка при флуде запросами, аномальной смене IP/VPN или попытке обхода бана через другой браузер с той же подсети.
* **Honeypot & Детектор эмуляторов:** Невидимые поля-ловушки для спам-ботов и автоматическое выявление `HeadlessChrome`, `Selenium` и `Puppeteer`.
* **Периметр защиты API:** Проверка клиентских заголовков (`X-Portal-Client`), защита от дубликатов и Rate-Limiting по IP.

### 🛠 Встроенная скрытая панель администратора (Admin Overlay)
* **Скрытый доступ:** Активируется кодовым словом `root` на клавиатуре или 5 быстрыми нажатиями на логотип-звезду.
* **Управление БД в один клик:** Просмотр сводной аналитики (`visitors_analytics`), кластеров IP-адресов, геолокации и мгновенная блокировка/разблокировка устройств.
* **System Health-Check & Global Error Boundary:** Встроенная диагностика задержки PostgreSQL, валидности токена бота и статуса Telegram Webhook, а также автоматическая отправка клиентских сбоев JS в Telegram владельцу.

## 🏗 Архитектура проекта

```text
pepel-zvezd-v2/
├── index.html                   # Адаптивный UI, Audio+Canvas Fingerprinting, Live-чат и Admin Overlay
```

## ⚙️ Переменные окружения (Vercel Environment Variables)

Для развёртывания проекта необходимы следующие переменные окружения:

| Переменная | Назначение |
| :--- | :--- |
| `TG_BOT_TOKEN` | Токен Telegram-бота от `@BotFather` |
| `TG_CHAT_ID` | ID закрытой супергруппы с включёнными темами (`Forum Topics`) |
| `OWNER_TG_ID` | Личный Telegram ID владельца для получения тех-досье и алертов об ошибках |
| `SUPABASE_URL` | URL проекта в Supabase (`https://supabase.co`) |
| `SUPABASE_KEY` | Секретный сервисный ключ API Supabase |
| `ADMIN_PASSWORD` | Пароль доступа к скрытой панели управления на сайте |
